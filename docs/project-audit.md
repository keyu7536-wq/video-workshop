# 通用项目交付范围与限制

本文描述源码当前的能力边界及需要继续改进的部分，不记录私人样片、账户或本机历史任务。具体安装与启动以项目 README 为准。

## 已有能力

- 接收文案、文章正文/链接、PDF、图片和视频，生成独立任务与可编辑分镜。
- 本机 Codex CLI 与兼容图片理解 API 两条模型调用路径，共用制作规范和结构化计划。
- 作者项目发现、仓库相关文件阅读、媒体发现清单、研究笔记及逐项来源引用；资料中的代码不会被执行。
- 固定版本的公开仓库选择性读取、补充材料发现、受支持平台单视频获取、文件内容去重与获取结果展示；获取失败保留原因。
- 文案保留校验、证据引文校验、镜头裁切/高亮、完整动作保留和实际配音驱动的时间线。
- 固定配音与可选自动节奏、词时间字幕、横竖屏/方形/自定义尺寸、多格式导出。
- 计划复核与实际成片复查分开；最终复核绑定文稿、配音/画面设置、渲染配置和视频版本。
- 默认无自动说明片尾。应用品牌、示例内容与用户任务不应构成业务逻辑依赖。

## 需要理解的边界

**通用输入不等于任意网站都能读取。** 当前工作台支持合计最多 400 页文字版 PDF、3 段用户视频、65 张分析图；粘贴单项正文最多 4 万字符、总提取文字最多 200 万字符。单份 PDF 下载上限 100 MB，默认至多抽样 24 张页面图，长正文按每批至多 6 万字符读取并保留可核验笔记。后续规划使用有范围记录的关键原文与来源目录。全文文字提取、分批阅读和页面视觉抽样分别记录，不能互相替代。联网研究还有独立预算和候选素材筛选，未下载或未检查的候选不算已审阅。

**代码阅读不等于复现实验。** 程序选择相关源码阅读并记录版本线索，不运行作者仓库。论文抽取不全、仓库身份不能确认、许可未说明或素材获取失败，都应保留为缺口。不要把一次关键词匹配当作已充分理解项目。

**目标时长是预算。** 实际录音、帧对齐、完整动作和短段余量共同决定片长。镜头计划里的图片时长是分配权重，不能直接宣称等于最终停留秒数。

**语音检查有不同层次。** Edge 路径使用服务提供的词时间；可选本地生成式语音链路包含独立识别/对齐。基础工作流没有为每一段 Edge 音频自动执行独立 ASR。内容核对未运行时不能写成已通过，ASR 结果也不能代替听感比较。数字比对还需区分真实数量与普通词语中的数字字符。

**自动复核不是发布保证。** 成片审核基于实际抽帧、文字和时间报告，不是每一帧或人耳完整观看。模型服务繁忙、超时和无法获取输入时，任务应保留未完成或待复核状态。关闭成片复核可以完成编码，但不意味着内容审核已通过。

**当前工作台面向本机。** 它不具备面向公网多用户部署的登录、权限、配额与任务隔离方案。源码包不包含模型权重、用户登录、私人媒体或已有任务；新使用者需自行配置依赖和模型服务。项目 ZIP 可能包含上传材料，分享前应检查其中内容与素材使用条件。

## 后续优化优先级

1. **逐句看图的自动安排。** 已有按旁白逐步放大和运动示意；继续改善自动选区与切点，使其更准确地指向当句正在解释的关系，并保留轴、图例和上下文。
2. **按镜头增量渲染。** 当前可以复用配音，普通完整渲染仍会重做镜头。缓存需覆盖素材内容、裁切、时长、字幕、画幅及渲染版本，并保留上一成功输出。
3. **按内容检查素材覆盖。** 现有界面已展示获取状态、去重数量、连续示意图及重复构图；后续进一步按文稿主题检查哪些观点有对应的实际画面，避免仅凭数量判断覆盖。
4. **字幕与发音细节。** 中英混排、长数字和单位采用实际字形测量；增加可编辑术语读音表与统一的自定义试听流程。
5. **移动主体与内部留白。** 已有素材级裁切及真实抽帧构图预览；固定裁框仍不能追踪移动主体，也不能自动判断所有内嵌边框和图例。继续改善自动建议与完整动作保护。
6. **可选语音环境的跨平台验证。** 本地模型的安装、硬件检测和依赖隔离仍需单独验证；基础 Edge 路径与本地模型测试应分别报告。

## 维护时如何验证

使用不含第三方研究素材和私人记录的合成示例做安装、编码与接口测试，再使用获得适当使用权限的论文和项目做人工内容验收。至少覆盖：有作者视频的论文、只有图表的论文、普通文章、自带文案与部分无关素材。切换模型后比较事实、讲述连续性、素材关系、字幕时序和错误拦截，不只检查输出 JSON 是否有效。
