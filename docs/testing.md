# 验证与发布

## 本地回归

使用 Python 3.11 或更新版本，安装基础与开发依赖：

```bash
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python -m unittest discover -s tests -p "test_*.py"
python scripts/smoke_render.py
python scripts/build_release.py --check
```

Linux 上可用 `python -m playwright install --with-deps chromium` 安装浏览器所需系统库，并按配置说明安装中文字体。

浏览器回归使用独立端口、临时目录和测试素材，不改动已有任务。模型接口与网络异常使用明确的测试替身；这类通过不能写成已验证真实模型服务。离线渲染生成图案和测试音，检查真实 FFmpeg 编码、解码、字幕与画幅，不代表正式配音自然度。

可选语音模型未安装时，相关测试会跳过。应同时记录通过、失败和跳过数，不能把跳过计为通过。

## 持续集成

GitHub Actions 对 Windows / Linux、Python 3.11 / 3.13 执行依赖安装、浏览器回归、离线渲染和源码发布扫描。测试不需要提供 Codex 登录、模型 API Key 或私人论文。

跨平台 CI 是代码和离线流程检查；完整模型、联网配音、硬件相关的本地语音和真实项目素材仍需要在相应环境中另行验证。

## 真实项目验收

发布前使用可公开、获得适当使用权限的资料核查：

1. 作者项目含演示视频的论文：确认来源识别、真实下载、抽帧、可选素材、片段播放和完整动作。
2. 主要依靠图表的论文：确认图表裁切、轴和单位、字幕安全区与事实限定。
3. 普通文章与已有文案：确认没有强制套论文结构，受保护文稿没有被擅自改写。
4. 失败与恢复：访问受限、下载中断、无效媒体、模型不可用、配音或导出失败应保留可继续处理的任务和明确错误。
5. 成片：核对真实时长、音轨、字幕、首末帧、关键动作和所有镜头的覆盖；播放试听另行记录。

明确区分自动检查、人工校订、实际观看与听音。自动审核必须对应当前文稿、设置、渲染配置和视频版本；修改后不能沿用旧审核结论。未完成的核查、失败或资料缺口应保留，不能为了发布而改成通过。

## 干净源码发布

```bash
python scripts/build_release.py --check
python scripts/build_release.py --version 0.3.1
```

构建器只选择明确允许发布的源码、测试和文档，生成 ZIP、SHA-256 校验文件及逐文件清单。已有版本不覆盖。解压到新目录，重新安装并执行回归和离线渲染，确认发布包可独立运行。

GitHub 仓库只推送干净源码。任务、作者媒体、模型权重、本机配置和凭据留在本机。首个公开版本应清楚说明已验证环境及剩余限制；公开源码不等于已经具备公网多用户部署能力。
